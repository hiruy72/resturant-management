# Restaurant-website

Simple full-stack restaurant website (backend + frontend).

## Quick start

- Install dependencies for backend and frontend:

```bash
cd backend
npm install

cd ../frontend
npm install
```

- Create an `.env` in `backend` with the required variables (see `backend/.env`).

- Run locally:

```bash
# backend
cd backend
npm run start

# frontend
cd ../frontend
npm run dev
```
